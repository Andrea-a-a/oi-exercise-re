# ICPC/CCPC 考场算法联想表（1s 时限打印版）

> **估算基准**：1s ≈ \(10^8\) 次简单运算。  
> 取模、递归、STL 容器、浮点、矩阵、网络流、后缀数组等常数大，实际往下降 1～2 档。  
> 表中“边缘”表示需要小常数、优化或卡常。  

---

## 1. 1s 复杂度预算速查

| 复杂度 | 稳妥可过 | 边缘 | 典型算法/备注 |

| \(O(n)\) | \(n\le10^7\) | \(5\times10^7\sim10^8\) | 线性筛、KMP、双指针、单调队列 |
| \(O(n\log n)\) | \(n\le10^6\) | \(2\times10^6\) | 排序、线段树建树、Dijkstra 小图 |
| \(O(n\log^2 n)\) | \(n\le2\times10^5\) | \(5\times10^5\) | 树剖、CDQ、主席树 |
| \(O(n\sqrt n)\) | \(n\le10^5\) | \(2\times10^5\) | 莫队、分块 |
| \(O(n^2)\) | \(n\le5000\) | \(10^4\) | 二维 DP、朴素 Dijkstra |
| \(O(n^2\log n)\) | \(n\le2000\) | \(3000\) | 二维 + 数据结构 |
| \(O(n^3)\) | \(n\le300\) | \(500\) | Floyd、区间 DP、高斯消元 |
| \(O(2^n)\) | \(n\le24\) | \(26\) | 枚举集合 |
| \(O(n2^n)\) | \(n\le20\) | \(22\) | 状压 DP |
| \(O(3^n)\) | \(n\le15\) | \(16\sim17\) | 枚举子集 DP |
| \(O(n!)\) | \(n\le10\) | \(11\) | 全排列暴力 |
| \(O(2^{n/2})\) | \(n\le40\) | \(44\) | 折半搜索、Meet-in-the-Middle |
| \(O(k^3\log n)\) | \(k\le100\) | \(150\) | 矩阵快速幂 |
| \(O(E\sqrt V)\) | \(V,E\le10^5\sim2\times10^5\) | \(5\times10^5\) | 二分图最大匹配 Hopcroft-Karp |

| \(O(n\log n)\) FFT/NTT | \(n\le10^5\) | \(5\times10^5\) | 常数大 |

## 2. 数据范围 → 候选算法

| 数据范围 | 优先候选 | 复杂度 | 备注 |
|---|---|---|---|
| \(n\le10\) | DFS、全排列、枚举子集、暴力 DP | \(O(n!)\)、\(O(2^n)\) | 怎么写都行 |
| \(n\le15\) | 子集枚举 DP、状压 DP | \(O(3^n)\)、\(O(n2^n)\) | \(3^{15}\approx1.4\times10^7\) |

| \(n\le40\) | Meet-in-the-Middle、双向 BFS | \(O(2^{n/2})\) | \(2^{20}\approx10^6\) |
| \(n\le100\) | Floyd、区间 DP、高斯消元 | \(O(n^3)\) | \(10^6\) 稳 |
| \(n\le300\) | Floyd、区间 DP、高斯消元 | \(O(n^3)\) | \(2.7\times10^7\) 稳 |
| \(n\le500\) | Floyd、\(O(n^3)\) | \(O(n^3)\) | \(1.25\times10^8\) 边缘 |
| \(n\le1000\) | 二维 DP、朴素 Dijkstra | \(O(n^2)\) | \(10^6\) 稳 |
| \(n\le2000\) | 二维 DP、\(O(n^2\log n)\) | \(O(n^2\log n)\) | 边缘看常数 |
| \(n\le5000\) | 二维 DP | \(O(n^2)\) | \(2.5\times10^7\) 稳 |
| \(n\le10^4\) | 分块、\(O(n\sqrt n)\) | \(O(n\sqrt n)\) | \(O(n^2)=10^8\) 边缘 |
| \(n\le10^5\) | 线段树、树状数组、莫队、树剖、二分 | \(O(n\log n)\)、\(O(n\sqrt n)\) | 主力区间 |
| \(n\le2\times10^5\) | 线段树、树剖、CDQ、主席树 | \(O(n\log n)\)、\(O(n\log^2 n)\) | 莫队边缘 |
| \(n\le5\times10^5\) | 线段树、排序、Hash、SA | \(O(n\log n)\) | \(O(n\log^2 n)\) 边缘 |
| \(n\le10^6\) | 线性筛、KMP、双指针、并查集 | \(O(n)\)、\(O(n\log n)\) | 注意内存和常数 |
| \(n\le10^7\) | 线性筛、桶、双指针 | \(O(n)\) | 边缘，少用 STL |
| \(n\le10^9\) | 试除、\(\sqrt n\) 枚举 | \(O(\sqrt n)\) | \(\sqrt n\approx31623\) |
| \(n\le10^{12}\) | 试除、质因数分解 | \(O(\sqrt n)\) | \(\sqrt n=10^6\) 稳 |
| \(n\le10^{14}\) | 试除 | \(O(\sqrt n)\) | \(\sqrt n=10^7\) 边缘 |
| \(n\le10^{18}\) | 快速幂、GCD、数位 DP、Miller-Rabin、矩阵快速幂 | \(O(\log n)\) | 不要枚举 |

## 3. 题面关键词 → 算法触发

### 3.1 图论

| 看到这些词/场景 | 首选算法 | 复杂度 | 1s/备注 |
|---|---|---|---|
| 连通性、扩散、有几个连通块 | DFS/BFS、并查集 | \(O(n+m)\) | \(10^6\) 稳 |
| 最少步数、无权最短路 | BFS | \(O(n+m)\) | \(10^6\) 稳 |
| 边权只有 0/1 | 0-1 BFS | \(O(n+m)\) | 双端队列 |
| 非负边权最短路 | Dijkstra + heap | \(O((n+m)\log n)\) | \(2\times10^5\) 稳，\(10^6\) 边缘 |
| 多源最短路 | 超级源 + Dijkstra/BFS | 同上 | 源点连所有起点 |
| 任意两点最短路，\(n\le300\sim500\) | Floyd | \(O(n^3)\) | 300 稳，500 边缘 |
| 负权边、判负环 | Bellman-Ford/SPFA | \(O(nm)\) | 小图；SPFA 慎用 |
| 所有点连通、铺网线成本最小 | Kruskal/Prim | \(O(m\log m)\)、\(O(n^2)\) | \(2\times10^5\) 稳 |
| 分成两组、互斥、不能相邻同组 | 二分图染色 | \(O(n+m)\) | 判奇环 |
| 二分图最大匹配 | Hopcroft-Karp | \(O(E\sqrt V)\) | \(V,E\le10^5\sim2\times10^5\) 稳 |
| 先后依赖、课程安排、任务前置 | 拓扑排序 | \(O(n+m)\) | 有环则无解 |
| DAG 路径计数、最长路 | 拓扑序 + DP | \(O(n+m)\) | DAG 专用 |
| 强连通分量、缩点 | Tarjan | \(O(n+m)\) | 缩点后变 DAG |
| 割点、桥、点双、边双 | Tarjan | \(O(n+m)\) | 注意 dfn/low |
| 树上最近公共祖先 | 倍增、欧拉序 + ST | \(O((n+q)\log n)\)、\(O(1)\) | \(q\le2\times10^5\) 稳 |
| 树上路径修改/查询 | 树剖 + 线段树、树上差分 | \(O(\log^2 n)\) | \(q\le2\times10^5\) 稳 |
| 最大流、最小割 | Dinic | 理论大，看规模 | 小图；\(V\le500,E\le5000\) 常见 |
| 互斥条件、选/不选 | 2-SAT | \(O(n+m)\) | Tarjan 缩点判同 SCC |
| 欧拉路径、一笔画 | Hierholzer | \(O(n+m)\) | 先判度数 |
| 旅行商、哈密顿，\(n\le20\) | 状压 DP | \(O(n^2 2^n)\) | \(n=20\) 稳 |
| 状态带方向/钥匙/血量 | 拆点、分层图 + BFS/Dijkstra | 同最短路 | 状态数乘层数 |

### 3.2 动态规划

| 看到这些词/条件 | 首选 DP | 复杂度 | 1s/备注 |
|---|---|---|---|
| 每步决策、前面影响后面 | 线性 DP | \(O(n\times状态)\) | 先定状态 |

| 树上选点、父子依赖、子树信息 | 树形 DP | \(O(n\times合并代价)\) | DFS 后合并 |
| \(n\le20\)，元素选/不选 | 状压 DP | \(O(n2^n)\) | \(n=20\) 稳，22 边缘 |
| 集合划分、枚举子集 | 枚举子集 DP | \(O(3^n)\) | \(n\le15\) 稳 |
| 数位限制、统计 \([L,R]\) 满足条件 | 数位 DP | \(O(len\times状态\times10)\) | \(len\le18\) |

| 计数 + 模 + 转移固定 | 矩阵快速幂 | \(O(k^3\log n)\) | \(k\le100\) 稳 |
| 期望、概率、随机游走 | 概率 DP/期望 DP | 视状态 | 有后效性用高斯消元/逆推 |
| 背包、选物品 | 01/完全/多重/分组背包 | \(O(nW)\) | \(W\le10^5,n\le100\) 稳；\(W\) 大 \(n\) 小用 MITM |
| 最长上升子序列 | 贪心 + 二分 | \(O(n\log n)\) | \(10^6\) 可 |
| 最长公共子序列、编辑距离 | 二维 DP | \(O(nm)\) | 5000 稳，\(10^4\) 边缘；bitset 可扩 |
| 网格轮廓线、插头 | 轮廓线 DP | \(O(nm2^m)\) | \(m\) 小 |
| 有后效性、环状转移 | 高斯消元、最短路建模 | \(O(n^3)\)、图算法 | \(n\le300\) |
| 博弈、必胜必败 | SG 函数、找规律 | 视 | 先手玩小数据 |

## 4. 组合信号：强条件反射

| 信号 | 条件反射 | 备注 |
|---|---|---|

| 多组询问 + 可离线 | 离线排序、莫队、整体二分 | 先问能否离线 |
| 值域大但点数少 | 离散化 | 排序去重 |
| 值域小 | 桶、权值线段树、计数排序 | 利用值域 |

## 5. 前提检查与易错清单

| 算法/套路 | 必须检查 | 易错点 |
|---|---|---|
| 二分答案 | 单调性成立 | check 边界、死循环 |
| 贪心 | 交换论证/反例 | 局部最优不等于全局最优 |
| DP | 状态完整、无后效性、转移不漏 | 初始化、多测清空 |
| Dijkstra | 边权非负 | 不能处理负权 |
| Floyd | 无负环 | INF 初始化、重边 |
| Kruskal | 无向图 | 排序、并查集 |
| 拓扑排序 | 有向无环 | 判环、入度 |
| 并查集 | 只合并不分裂 | 路径压缩、按秩合并 |
| 莫队 | 离线、可增删 | 块大小、排序 |
| 树剖 | 静态树 | DFS 序、重儿子 |
| 主席树 | 静态值域、前缀可减 | 内存、离散化 |
| Hash | 冲突 | 双哈希、随机基 |
| 网络流 | 建图、容量 | 反向边、INF |
| 2-SAT | 对称建边 | 缩点后判同 SCC |
| 矩阵快速幂 | 转移固定 | 单位矩阵、取模 |
| 浮点几何 | eps 设置 | 输出精度、共线 |
| 多测 | 全局数组清空 | 容器、邻接表 |
| 内存 | 256MB 约 \(6.7\times10^7\) int | 二维数组、long long |
| 递归 | 栈深度 | \(10^5\) 深改迭代/扩栈 |
| 取模 | 负数取模 | \((a\%mod+mod)\%mod\) |
| long long | 乘法溢出 | 1e18 级别注意 |

## 6. 考场流程（打印版）

1. **读题扫参数**：\(n,m,q\)、值域、时限、内存、多测、模数、是否强制在线、输出格式。  
2. **定目标**：可达性 / 最短路 / 计数 / 最值 / 构造 / 判定。  
3. **先排除**：用数据范围表排除复杂度不可能的算法。  
4. **再触发**：用关键词表列 2～3 个候选，不要超过 3 个。  
5. **验前提**：二分查单调性，贪心找反例，DP 查后效性，Dijkstra 查负权。  
6. **估内存**：256MB 下 int 约 \(6.7\times10^7\)，long long 约 \(3.3\times10^7\)。  
7. **先暴力**：写暴力/check，小数据对拍，再上正解。  
8. **卡常**：快读、数组、bitset、避免递归、STL reserve。  
9. **终检**：多测清空、long long、边界、取模、输出格式。
